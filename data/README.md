# Acervo importado

Os arquivos de jurisprudência desta pasta são gerados por `scripts/import_stj.py` a partir de fontes oficiais do STJ e salvos pela rotina de publicação. `manifest.json` identifica a quantidade de registros, o recorte, os conjuntos de origem e os hashes de cada arquivo comprimido.

Não edite as ementas importadas manualmente. A ausência de um tribunal neste manifesto significa que seu acervo não está integrado. Consulte `INTEGRACOES.md` para ver o alcance real e ativar a consulta ao TJDFT.
